# Kuantum Hesap Makinesi (Ama Değil)

## Devrim Niteliğinde Bir İcat

Bu hesap makinesi, kuantum süperpozisyon, dolanıklık, tünel etkisi ve bolca "yok artık" kullanarak çalışır.

**Özellikleri:**
- 2 + 2'yi genellikle 5 yapar
- Bazen 42 yapar (Hitchhiker's Guide onaylı)
- Bazen sadece "çay iç" der
- Gerçek kuantum bilgisayar değildir. Hiçbir şey kuantum değildir burada. Sadece isim öyle.

## Kullanım

```bash
python hesap_makinesi.py
```

Sonra işlem girin. Sonuç sizi şaşırtacak (veya şaşırtmayacak).

## Neden Var Bu?

Çünkü normal hesap makineleri çok sıkıcı. Bu ise **eğlenceli şekilde yanlış**.

## Gelecek Planlar

- Kuantum çay demleme entegrasyonu
- Fal okuma modu
- Sonsuza kadar 1 ekleyen mod
